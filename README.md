# ATM Management System

A beginner-friendly ATM Management System developed using Python and SQLite.

## Features

- Create Account
- PIN-based Login
- Check Balance
- Deposit Money
- Withdraw Money
- Transaction History
- Logout
- SQLite Database Integration

## Technologies Used

- Python
- SQLite
- PyCharm

## Project Files

- `main.py` - Main ATM application
- `database.py` - Creates the SQLite database and accounts table
- `.gitignore` - Prevents database and unnecessary files from being uploaded

## How to Run

1. Install Python.
2. Open the project in PyCharm.
3. Run `database.py` to create the database.
4. Run `main.py` to start the ATM system.
5. Create an account or login using an existing account.

## Project Purpose

This project was developed as a learning project to understand Python functions, SQLite database integration, account management, and transaction handling.
